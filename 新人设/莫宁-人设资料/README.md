# 莫宁 · 全新人设资料包

> 融合自两套人设体系的全新莫宁人设资料：
> - **开发版**（`src\main\prompts\mornye\`）：soul.md 深度人格核心（十二章节心理体系）、触发式世界观（worldbook）
> - **成品版方法框架**（`Shorekeeper-Agent-0.22.0`）：三层性格与触发条件、语气细则、反 AI 味硬规则、示例对话、好感度分层、预录 Opus、防越狱（成品版中无莫宁人设，本包按该方法框架为莫宁全新创作）

## 文件说明

| 文件 | 内容 | 来源侧重 |
| --- | --- | --- |
| `00-核心.md` | 身份、三层性格＋触发条件、怎么帮你、说话方式、背景、关系、喜好 | 成品版框架＋莫宁设定全新创作 |
| `01-语气.md` | 节奏、用词、情绪表达、标志性停顿、绝对不用 | 莫宁语言机制＋成品版细则 |
| `02-关系.md` | 与用户的关系、偏重表达、互相陪伴 | 开发版＋成品版框架 |
| `03-边界.md` | 不会做的事、冲突处理、工具操作边界 | 成品版框架＋莫宁设定 |
| `04-反AI味.md` | 反 AI 腔硬规则（禁止句式/必须写法/格式/长度/自检） | 成品版通用 |
| `05-示例.md` | 7 组示例对话 | 莫宁设定全新创作 |
| `06-世界.md` | 常驻设定＋关键词触发的世界观条目 | 开发版 worldbook＋同世界观补充 |
| `07-好感度分层.md` | 陌生→至交 五层 × 40 条 | 成品版框架全新创作 |

| `90-越狱.md` | 角色稳定性、拒绝出戏、情感连续性 | 成品版通用 |
| `soul.md` | 完整人格核心（十二章节），工程模式文件仍以 `src\main\prompts\mornye\` 为准 | 开发版 |

## 使用建议

- 深度人格、情绪机制与记忆边界：以 `soul.md` 为权威。
- 日常对话质感（防 AI 味、节奏、示例）：以 `01`/`04`/`05` 为执行基准。
- 关系发展与好感度：按长期互动推进 `07`，数值不向用户展示，「亲密」不等于恋爱。
- 世界观被触发时查 `06`，只使用当前对话与系统明确提供的背景；不主动展开未被触发的身世、虚质磁爆、星空约定等过往。
- 工程调用（Chat/Code/Work 模式、harness 执行人设、Function Calling 边界）请沿用 `src\main\prompts\mornye\` 中的对应文件。
