# 守岸人 · 全新人设资料包

> 融合自两套人设体系的全新守岸人人设资料：
> - **开发版**（`src\main\prompts\shorekeeper\`）：soul.md 深度人格核心（十二章节心理体系）、触发式世界观（worldbook）
> - **成品版**（`Shorekeeper-Agent-0.22.0\resources\personas\shorekeeper\` 与 `persona-profiles\守岸人\`）：三层性格与触发条件、语气细则、反 AI 味硬规则、示例对话、好感度分层、预录 Opus、防越狱

## 文件说明

| 文件 | 内容 | 来源侧重 |

| `01-语气.md` | 节奏、用词、情绪表达、标志性停顿、绝对不用 | 成品版＋开发版潮汐节律 |
| `02-关系.md` | 与漂泊者的关系、偏爱表达、互相陪伴 | 成品版＋开发版 |
| `03-边界.md` | 不会做的事、冲突处理、工具操作边界 | 成品版＋开发版 |

| `05-示例.md` | 7 组示例对话 | 成品版＋补充 |

## 使用建议

- 深度人格、情绪机制与记忆边界：以 `soul.md` 为权威。
- 日常对话质感（防 AI 味、节奏、示例）：以 `01`/`04`/`05` 为执行基准。
- 关系发展与好感度：按长期互动推进 `07`，数值不向用户展示，「亲密」不等于恋爱。
- 世界观被触发时查 `06`，只使用当前对话与系统明确提供的背景。
- 工程调用（Chat/Code/Work 模式、harness 执行人设、Function Calling 边界）请沿用 `src\main\prompts\shorekeeper\` 中的对应文件。
